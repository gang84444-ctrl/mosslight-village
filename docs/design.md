# 모스라이트 마을 — 설계와 구현 계획

사용자가 요청한 3D 마을과 GitHub 업로드에 맞춰 에이전트가 선택한 설계.

- Three.js + Vite, 별도 이미지나 모델 다운로드 없이 기본 도형으로 만든 오리지널 3D 섬.
- 부드러운 파스텔 색, 그림자, 바다, 숲, 집, 텃밭, 광장, 동물 주민.
- 방향키/WASD 및 화면 터치로 이동, 마우스 드래그로 시점 회전, 휠로 확대.
- 주민 대화, 열매 수집, 가구 구매 및 배치, 방문 목표와 브라우저 자동 저장.
- 서버를 실행하면 위치와 채팅만 실시간 공유. 장식과 수집은 개인 저장.
- GitHub Pages는 정적 싱글 플레이. 계정, 영구 서버 DB, 거래, 집 내부는 범위 밖.
- 다른 게임의 이름, 캐릭터, 음원, 모델을 포함하지 않는다.

## 구현 순서
1. `src/game.js`: 이동/충돌, 수집 쿨다운, 장식 구매, 저장 복원. `tests/game.test.js`로 잘못된 입력과 중복 보상부터 검증.
2. `src/world.js`: 섬과 주민 3D 모델, 조명, 카메라, 선택과 이동.
3. `src/main.js`, `src/style.css`: 한국어 HUD, 인벤토리, 미션, 설정, 사진, 터치 입력.
4. `server.js`, `src/network.js`: 같은 서버의 방문자 위치 및 채팅, 제한된 요청 크기, 세션 검증. 실제 HTTP 통합 테스트.
5. GitHub Pages 자동 배포, 한국어 README, 라이선스. 테스트/빌드 및 브라우저로 화면과 주요 동작 확인.

## 검증 중점
물과 건물 통과 방지, 재수확 쿨다운, 부족한 잔액, 손상된 저장 파일, 연결 끊김과 정적 호스팅 대체 동작.
