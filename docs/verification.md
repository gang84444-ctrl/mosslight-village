## v1.1.0 실행용 다운로드 수정

- 증상: 개발용 소스 HTML만 열면 스타일과 JS가 로드되지 않아 글자만 표시될 수 있음.
- 실행용 단일 HTML에 빌드한 JS, CSS, Three.js 라이선스를 포함. 외부 글꼴 요청 제거.
- `file:` 환경에서 서버 연결을 시도하지 않고 혼자 플레이. 별도 설치 불필요.
- `npm test`: 총 13개 통과. 실행 파일에 필요한 코드·스타일 포함, 개발용 HTML 패키징 거부, 오프라인 API 차단 테스트 추가.
- 실행용 단일 HTML을 로컬 HTTP로 열어 3D 화면, 스타일, 낮/밤, 주머니 버튼 확인.
- 자동 브라우저의 보안 정책이 `file:` 주소 접근을 차단하므로, 더블 클릭 실행 자체는 자동 검증하지 못함. 외부 의존 파일이 없다는 점은 패키징 테스트와 코드 검토로 확인.
